HTTP Status Codes and Their Use Cases

1xx - Informational Responses:
100 CONTINUE – The client can continue sending the request body after an initial request check by the server.
101 SWITCHING_PROTOCOLS – The server agrees to switch protocols (e.g., from HTTP to WebSocket).
102 PROCESSING – The server is processing a long-running request and hasn’t completed yet.
103 EARLYHINTS – Used for preloading resources before the final response.

2xx - Successful Responses:
200 OK – Standard response for successful HTTP requests.
201 CREATED – Used when a new resource has been successfully created.
202 ACCEPTED – The request has been received but is being processed asynchronously.
203 NON_AUTHORITATIVE_INFORMATION – Response from a proxy that modified the original response.
204 NO_CONTENT – The request was successful, but there is no content to return.
205 RESET_CONTENT – Instructs the client to reset the document view (e.g., a form submission reset).
206 PARTIAL_CONTENT – Used when returning a portion of the requested resource (e.g., for resuming downloads).
3xx - Redirection Responses
300 AMBIGUOUS – Multiple possible responses, and the client must choose.
301 MOVED_PERMANENTLY – The resource has been permanently moved to a new URL.
302 FOUND – Temporary redirect; the resource is temporarily available at a different URL.
303 SEE_OTHER – Redirects the client to a different resource, often used after a POST request.
304 NOT_MODIFIED – The cached version of the resource is still valid.
307 TEMPORARY_REDIRECT – Similar to 302, but the method must remain unchanged.
308 PERMANENT_REDIRECT – Similar to 301, but the method must remain unchanged.

4xx - Client Errors:
400 BAD_REQUEST – The server cannot process the request due to client error (e.g., invalid input).
401 UNAUTHORIZED – Authentication is required or has failed.
402 PAYMENT_REQUIRED – Reserved for future use (sometimes used in APIs for payment failures).
403 FORBIDDEN – The client does not have permission to access the resource.
404 NOT_FOUND – The requested resource was not found.
405 METHOD_NOT_ALLOWED – The request method is not allowed for this resource.
406 NOT_ACCEPTABLE – The resource cannot be returned in the requested format.
407 PROXY_AUTHENTICATION_REQUIRED – Authentication is required via a proxy.
408 REQUEST_TIMEOUT – The client took too long to send a request.
409 CONFLICT – The request conflicts with the server’s current state (e.g., duplicate resource creation).
410 GONE – The resource is no longer available and won’t return.
411 LENGTH_REQUIRED – The request must include a Content-Length header.
412 PRECONDITION_FAILED – A precondition specified in the request headers failed.
413 PAYLOAD_TOO_LARGE – The request payload is too large for the server to process.
414 URI_TOO_LONG – The URL is too long for the server to handle.
415 UNSUPPORTED_MEDIA_TYPE – The request has an unsupported media type.
416 REQUESTED_RANGE_NOT_SATISFIABLE – The requested byte range is not valid.
417 EXPECTATION_FAILED – The server cannot meet the expectations set in the request headers.
418 I_AM_A_TEAPOT – A joke status code from RFC 2324 (Hyper Text Coffee Pot Control Protocol).
421 MISDIRECTED – The request was sent to the wrong server.
422 UNPROCESSABLE_ENTITY – The request is well-formed but cannot be processed due to semantic issues.
424 FAILED_DEPENDENCY – The request failed due to a failure in a dependent operation.
428 PRECONDITION_REQUIRED – The server requires the request to include a precondition.
429 TOO_MANY_REQUESTS – The client has sent too many requests in a short period (rate limiting).


5xx - Server Errors:
500 INTERNAL_SERVER_ERROR – A generic server error.
501 NOT_IMPLEMENTED – The server does not support the request method.
502 BAD_GATEWAY – The server received an invalid response from an upstream service.
503 SERVICE_UNAVAILABLE – The server is overloaded or undergoing maintenance.
504 GATEWAY_TIMEOUT – The server did not receive a response from an upstream service in time.
505 HTTP_VERSION_NOT_SUPPORTED – The HTTP version used is not supported by the server.
