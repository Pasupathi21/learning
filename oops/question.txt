What is Object Oriented Programming ?
    Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects," which encapsulate data and behavior. 
 It helps in designing modular, reusable, and scalable code.

    Key Concepts of OOP:
        Class – A blueprint for creating objects.
        Object – An instance of a class with its own data and methods.
        Encapsulation – Hiding the internal details and exposing only necessary parts.
        Abstraction – Hiding complex implementation and showing only essential details.
        Inheritance – Allowing a class to derive properties and behavior from another class.
        Polymorphism – Enabling a single interface to be used for different data types.
